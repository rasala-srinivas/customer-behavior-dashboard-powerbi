# Customer Behavior Dashboard

## Project Overview
This Power BI dashboard analyzes customer purchasing behavior, demographics, subscription status, and product preferences.

## Business Objective
To identify customer purchasing trends and segment customers based on demographic and behavioral attributes.

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization

## Key Features
- Customer Segmentation
- Revenue Analysis
- Sales Analysis
- Subscription Status Tracking
- Purchase Behavior Monitoring
- Interactive Filters and Slicers

## KPIs
- Number of Customers
- Average Purchase Amount
- Average Review Rating
- Revenue by Category
- Sales by Age Group

## DAX Measures Used
- Average Purchase Amount
- Total Revenue
- Customer Count
- Average Review Rating

## Outcome
Built an interactive Power BI dashboard that enables customer-centric decision-making through behavioral analytics and data visualization.
